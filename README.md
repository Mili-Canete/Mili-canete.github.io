Portfolio — Milagros Cañete

Portfolio personal como desarrolladora Full Stack orientada al frontend. Una única página, sin frameworks, pensada para acompañar mi CV: presentación, stack, proyectos, experiencia y contacto.

🔗 Sitio en vivo: https://mili-canete.github.io

✨ Características
Diseño minimalista con paleta en tonos tierra
Modo claro / oscuro (recuerda la preferencia del visitante)
Totalmente responsive (adaptado a celular)
Animaciones suaves al hacer scroll, respetando prefers-reduced-motion
Un solo archivo index.html, sin dependencias ni build
🛠️ Tecnologías
HTML5
CSS3 (variables, grid, flexbox)
JavaScript (vanilla)
🚀 Cómo verlo localmente

Al no tener build, alcanza con abrir el archivo:

bash
# cloná el repo
git clone https://github.com/Mili-Canete/Mili-Canete.github.io.git

# y abrí index.html en el navegador (doble clic)
🌐 Publicar con GitHub Pages
Renombrá el archivo a index.html y subilo al repositorio.
Entrá en Settings → Pages.
En Source elegí la rama main y la carpeta /root.
En unos segundos tu portfolio queda online.

💡 Si nombrás el repositorio Mili-Canete.github.io, el sitio se publica directamente en https://mili-canete.github.io (sin subcarpeta).
